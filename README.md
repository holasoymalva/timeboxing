# Timeboxium

## 🚀 The Ultimate Productivity Tool for High-Achievers

**Timeboxium** is a sleek, minimalist web application designed to help ambitious professionals, entrepreneurs, and creators maximize their daily productivity through effective timeboxing techniques.

## ✨ Features

- **Streamlined Interface**: Distraction-free design with dark mode for focused productivity
- **Top Priorities**: Clearly define your 3 most important tasks for the day
- **Brain Dump**: Capture your thoughts, ideas, and mental noise in one place
- **Hour-by-Hour Planning**: Schedule your entire day in 30-minute increments
- **Data Persistence**: Your plan remains intact even when you close or refresh the browser
- **Responsive Design**: Works seamlessly across all devices - desktop, tablet, and mobile

## 🔍 Why Timeboxing?

Timeboxing is a time management technique used by highly successful people including Elon Musk, Bill Gates, and Cal Newport. It involves allocating fixed time periods (timeboxes) to activities, increasing focus, reducing procrastination, and bringing clarity to your day.

Our application brings this powerful technique to the digital space with a thoughtfully designed interface that promotes focus and intentionality.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14+)
- npm (v6+)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/holasoymalva/timeboxing.git
   cd timeboxing
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Run the development server
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Deployment

Deploy to GitHub Pages with a single command:

```bash
npm run deploy
```
